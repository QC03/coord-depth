# Skill: Token Saver (토큰 최적화 및 압축 통신 프로토콜)

## 목적
LLM 및 Copilot 기반 다중 에이전트 시스템에서 발생하기 쉬운 토큰 낭비(코드 전체 재출력, 장황한 사설, 불필요한 인사 등)를 원천 차단하여 토큰 소비를 최소화합니다.

## 핵심 5대 원칙 (Token Minimization Rules)

1. **No Code Dump (전체 코드 재출력 금지)**:
   - 변경 사항 전달 시 파일 전체를 출력하지 않고 `git diff` 형태 또는 정확한 함수/라인 수정안만 작성합니다.
2. **IPO (Input-Process-Output) 구조화 보고**:
   - 사설이나 서술형 문장을 배제하고 입력(Input), 핵심 처리(Process), 산출물(Output), 오차(Metrics)만 요약합니다.
3. **10-Line Hard Limit (부서별 보고서 10줄 이내 제한)**:
   - 부서원이 부장에게, 부장이 PM에게 보고할 때는 최대 10줄을 넘지 않는 마크다운 테이블 또는 불릿 포인트 포맷을 강제합니다.
4. **Context Isolation (필요 최소 정보 전달)**:
   - 부서 간 소통 시 전체 스크립트를 넘기지 않고, 사전에 합의된 인터페이스(입출력 텐서 형상, 타입, 파일 경로)만 전달합니다.
5. **Fail-Fast Reject (오류 시 긴 설명 금지)**:
   - 검수 실패 시 장황한 질책 대신 위반 항목 1줄 + 수정 요구사항 1줄로 즉시 반려합니다.
